## Project Overview

PayEase is a fintech mobile application wireframe designed using Figma as part of the CODTECH UI/UX Design Internship.

The project aims to establish a clear and user-friendly interface for a digital banking application. It focuses on structuring essential banking functionalities, organizing financial information, and creating a consistent mobile user experience through low-fidelity wireframing.

## Project Objectives

- To understand and apply fundamental UI/UX design principles.
- To develop a structured mobile banking application layout.
- To design intuitive and accessible user interfaces.
- To establish consistent visual hierarchy across application screens.
- To simplify user interactions through effective interface organization.
- To gain practical experience in mobile application wireframing using Figma.

## Project Scope

This project covers the wireframe development of a fintech mobile application with four essential interfaces. It focuses on the overall screen structure, content arrangement, navigation flow, and usability of a digital banking application.

The design emphasizes functionality and layout organization rather than detailed visual styling.

## Work Done

1. Planned and structured the overall layout of the PayEase mobile application.
2. Designed an organized authentication interface for user access.
3. Developed a financial dashboard to present account information and essential banking services.
4. Created a structured interface for initiating money transfers.
5. Designed a transaction history interface for organizing financial activities.
6. Maintained consistent spacing, alignment, and layout patterns throughout the application.
7. Applied a minimal grey-scale design approach suitable for low-fidelity wireframing.
8. Created and exported the final mobile wireframes using Figma.

## Project Deliverables

- Login Screen
- Home Screen
- Money Transfer Screen
- Transaction History Screen
- Complete Figma Design Link

## Tools Used

- **Figma:** Used for creating mobile application wireframes, arranging interface elements, and designing screen layouts.
- **UI/UX Design Principles:** Applied to improve interface structure, usability, consistency, and navigation.

## Design Methodology

The project follows a **Low-Fidelity Wireframing** approach.

- **Layout Structuring:** Organized interface elements based on their purpose and functionality.
- **Visual Hierarchy:** Arranged content to establish clear information priorities.
- **Consistency:** Maintained uniform spacing, alignment, and component placement.
- **Minimal Design:** Used a simple grey-scale colour scheme to emphasize structure and functionality.
- **Usability:** Focused on creating a straightforward and understandable mobile navigation experience.
